Privacy Policy: Bodycam Uploader

Last updated: September 28, 2026

Bodycam Uploader is a private tool used only by the owner of the YouTube channel BodyCamClipsUSA.

What it accesses

With the owner's permission, the tool uses the YouTube Data API to upload videos, set thumbnails, add captions and read basic channel details for the owner's own channel. It does not access any other user's account or data.

What it stores

The only thing stored is the owner's OAuth authorization token, kept as an encrypted secret so the tool can upload on the owner's behalf. No personal data about other people is collected, stored, sold or shared.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also follows the YouTube Terms of Service; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
